# PWA محاسبه چک

فایل‌ها:
- index.html: نسخه PWA شده برنامه اصلی
- manifest.json: مشخصات نصب روی iPhone/Android
- sw.js: کش آفلاین برنامه
- icons/: آیکون‌های PWA

## استفاده
این فایل‌ها را روی یک هاست HTTPS قرار دهید و `index.html` را باز کنید.

در iPhone با Safari:
Share → Add to Home Screen

نکته: Service Worker و نصب PWA در مرورگرهای مدرن نیاز به HTTPS دارد (به‌جز localhost).
